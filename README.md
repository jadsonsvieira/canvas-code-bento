# Canvas & Code — Bento Showroom 🎨💻

> **Showroom Digital Interativo & Funil de Conversão UI/UX**  
> Desenvolvido sob a vertical **Canvas & Code** / **MJSV Holding**.

---

## 📌 Visão Geral

O **Canvas & Code Bento** é uma landing page de alta fidelidade visual projetada com a tendência estética de **Bento Grid**. Funciona como showroom interativo de serviços de design de interfaces, pitch decks executivos, protótipos de alta fidelidade e desenvolvimento de landing pages.

---

## ✨ Principais Funcionalidades

- **Layout Bento Grid Ultra-Moderno**: Organização modular de projetos, portfólio e proposta de valor em cartões interativos.
- **Seletor Dinâmico de Moeda (BRL / USD)**: Conversão e adaptação instantânea de preços para atender tanto o mercado brasileiro (Workana, 99Freelas) quanto internacional (Fiverr, Upwork).
- **Terminal Mockup & Micro-Interações**: Elementos visuais que comunicam sofisticação técnica e refinamento estético.
- **Funil Lead Magnet & Redirecionamento**: Botões de ação direta para agendamento e contratação via WhatsApp Business e canais oficiais.
- **Hospedagem Automática via GitHub Pages**: Integração contínua e publicação instantânea.

---

## 🛠️ Stack Tecnológica

- **Frontend**: HTML5 Semântico, CSS3 Moderno (Grid Layout, Flexbox, Glassmorphism, Variáveis CSS), JavaScript Vanilla
- **Deploy & Hospedagem**: GitHub Pages com GitHub Actions automatizado

## 🚀 Execução Local

```bash
# Clonar o repositório
git clone https://github.com/jadsonsvieira/canvas-code-bento.git
cd canvas-code-bento

# Iniciar servidor local
python -m http.server 8080
```
Abra no navegador em `http://localhost:8080`.
